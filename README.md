# StudyQueue: Task Management System

## Description
StudyQueue is a console-based task management system developed using the C programming language. The system helps users organize and manage study-related tasks efficiently.

## Features
- Add Task
- View Tasks
- Search Task
- Sort Tasks by Priority
- Mark Task as Done
- Delete Task
- View Completed Tasks

## Data Structures Used
- Array
- Stack
- Queue

## Algorithms Used
- Linear Search
- Bubble Sort
