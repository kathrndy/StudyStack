# StudyStack: Smart Study Planner System

## Overview
This is a console-based application written in C that helps students manage their study tasks. It allows users to organize, prioritize, and track their tasks.

## Features
- Add Task
- View Tasks
- Search Task
- Sort Tasks (by priority)
- Mark Task as Done
- Delete Task

## Data Structures Used
- Array (used to store multiple tasks)
- Structure (used to define task attributes)

## Algorithms Used
- Linear Search (to find tasks)
- Bubble Sort (to sort tasks by priority)

## How to Run
1. Open Dev-C++
2. Copy the code
3. Compile and run
